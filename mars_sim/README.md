# TERRA ASCENDANT — 人類昇天（火星探査シミュレーション）

神の視座で、特定の国家や企業ではなく **「人類という種」** を主語に、
地球低軌道から火星定住までの宇宙進出を導くハードSFシミュレーションゲーム。

設計方針は一貫して **「出来る限り現実の物理・工学・経済・人間に忠実に」**。

## プレイヤーの役割 — 「二重の視座」
- **ミクロ（国家）**：開始時に1国を選び、その国にのみ直接指示する（予算・R&D・ミッション・外交）。
- **メゾ（自律世界）**：他国・企業・国際機関は自律的に動く。命令はできず、自国を通じて間接的に影響するのみ。
- **マクロ（神）**：気候・経済・地政学・パンデミック・宇宙環境など、地球全体に関わるイベントは“神”として支配する。
