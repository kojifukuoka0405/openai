# 火星探査シミュレーション（仮題：**TERRA ASCENDANT — 人類昇天**）

> 神の視座で、特定の国家ではなく「人類という種」を主語に、地球周回軌道から火星定住までの宇宙進出を導くハードSFシミュレーション。
> 設計方針は一貫して **「出来る限り現実の物理・工学・経済・人間に忠実に」**。

---

## 0. ログライン

> 西暦2030年代。分断された地球文明は、はじめて「種としての生存戦略」を問われる。
> あなたは特定の国でも企業でもない。人類の集合的意志そのもの——歴史の流れを少しずつ傾ける**見えざる手**だ。
> 軌道に橋を架け、月に足場を築き、火星に種をまく。失敗は人を殺し、政治は計画を裂き、宇宙は容赦しない。
> それでも人類を、地球という揺りかごの外で自立させられるか。

## 1. コンセプトの三本柱

1. **神の視座 / 人類が主語**
   プレイヤーは「アメリカ」「中国」「SpaceX」を演じない。プレイヤーが操るのは**人類全体の趨勢**。
   ただしリアリティのため「人類は一枚岩ではない」ことを中核に据える。プレイヤーは命令するのではなく、
   各勢力（国家ブロック・企業・国際機関）を**誘導・調停・出資配分**する。直接操作ではなく**間接統治（god-game）**。

2. **徹底したリアリズム**
   軌道力学（打ち上げ窓・Δv・遷移時間）、ロケット工学（多段化・再使用・推進剤）、ISRU（現地資源利用）、
   生命維持（閉鎖系ECLSS）、放射線、人体への影響、コスト構造——全て実在の数値・物理に基づくモデルで駆動する。
   「魔法のような技術」は出さない。技術ツリーは2026年時点で原理実証済み or 理論的に妥当なものに限定。

3. **長期の文明シミュレーション**
   1ターン＝数週間〜数ヶ月。1キャンペーン＝**約100年（2030s→2130s）**。
   個々のミッションの戦術ではなく、世代をまたぐ**戦略と帰結**を楽しむ。

## 2. プレイヤーの役割と「神の視座」の定義

プレイヤー＝ **Stewardship Council（人類管理評議会）という抽象的存在**。
直接できることは「資源の配分」「方針の提示」「危機への介入」の3種に限定される。
これがリアリティ（人類は中央集権で動かない）とゲーム性（戦略的選択）を両立させる肝。

### 操れるもの
- **Influence（影響力ポイント）**：各勢力への働きかけ、政策誘導、国際協定の締結に使う基軸リソース。
- **Funding allocation（出資配分）**：複数の資金源（公的予算・民間資本・国際ファンド）の流れを傾ける。
- **R&D priority（研究優先度）**：技術ツリーのどこに人類の英知を集中させるか。
- **Crisis intervention（危機介入）**：事故・政治対立・災害時に Influence を投じて流れを変える。

### 操れないもの（あえて）
- 個々のロケットの手動操縦（＝ Kerbal 的な操作はしない。あくまで戦略レイヤー）。
- 勢力の完全支配（反発・離脱・サボタージュが起こりうる）。
- 物理法則のねじ曲げ。

## 3. リアリティの柱（科学的基盤モデル）

各システムは「実数ベースのシンプルなモデル」で実装する。下表は実装時の基準値の出典イメージ。

| 領域 | モデル化する要素 | 代表的な現実値（基準） |
|---|---|---|
| 軌道力学 | 打ち上げ窓・Δv・遷移時間 | 地球→火星 Hohmann 窓は約26ヶ月毎、片道約6〜9ヶ月、地表→LEO Δv≈9.4 km/s、LEO→火星遷移 Δv≈3.6 km/s |
| ロケット | 質量比・比推力(Isp)・多段・再使用 | ケロシン/LOX Isp≈300s、メタン/LOX≈360s、水素/LOX≈450s、再使用で$/kgが桁で低下 |
| 打ち上げコスト | $/kg to LEO の時代変化 | 使い捨て大型≈$2,000〜10,000/kg、再使用超大型で$100〜$1,000/kg台へ |
| ISRU | 推進剤・水・酸素の現地生成 | Sabatier反応（CO₂+H₂→CH₄+H₂O）、火星大気95%CO₂、極冠・地下の水氷 |
| 生命維持 | 閉鎖系の物質収支 | 1人/日：酸素≈0.84kg、水≈3〜4L(飲用)、食料≈0.6kg乾燥、CO₂除去、水・空気リサイクル率 |
| 放射線 | GCR・SPE・遮蔽 | 火星往復で約0.3〜0.6 Sv被曝、レゴリス/水による遮蔽、太陽嵐の確率イベント |
| 重力影響 | 微小重力・部分重力の健康劣化 | 微小重力で骨量月1〜1.5%減・筋萎縮、火星重力0.38gの長期影響は未知（ゲーム内は不確実性として扱う） |
| 着陸 | EDL（突入・降下・着陸） | 火星は大気が薄く重い質量の着陸が難問（"supersonic retropropulsion"等）、失敗確率を質量・技術で表現 |
| 人間 | 乗員の健康・士気・スキル・寿命 | 隔離・閉鎖環境ストレス、医療限界、世代交代 |

> 実装上は「正確な軌道伝播計算」までは初期版では持たず、**事前計算した遷移コスト表＋確率モデル**で“説得力のあるリアリティ”を出す。
> 上級モードで簡易patched-conicsによるΔv計算を有効化できる拡張余地を残す。

## 4. ゲームシナリオ（キャンペーン構成）

キャンペーンは5つの **Act（時代）** で構成。各Actは固有の課題・技術・ドラマを持つ。
史実の延長線上から始まり、プレイヤーの選択で歴史が分岐する。

### Act I — 「軌道の橋」（2030s）｜地球低軌道(LEO)経済の確立
- **状況**：再使用ロケットが$/kgを下げ始め、宇宙が「探検」から「産業」へ移行する黎明期。だが各勢力はバラバラ。
- **目標**：打ち上げコスト低減、軌道インフラ（基地・燃料デポ）、国際協調の最初の枠組み構築。
- **ドラマ**：商業 vs 公的セクターの主導権争い。最初の大型事故。デブリ問題の顕在化。
- **学びの主題**：Δv とコストの感覚をプレイヤーに教えるチュートリアル的Act。

### Act II — 「足場としての月」（2040s）｜シスルナ経済と実証
- **状況**：月は火星への“リハーサル”。低Δv・短通信遅延で技術を枯らす場所。
- **目標**：月面基地、水氷ISRUによる推進剤生産、月軌道ステーション（ゲートウェイ型）。
- **ドラマ**：資源（月の水・ヘリウム・希少金属）を巡る地政学。最初の死者の出る月面事故。
- **鍵**：ここでISRUと閉鎖生命維持を“安全な近場”で確立できるかが、火星の成否を決める。

### Act III — 「赤い窓」（2050s）｜有人火星到達
- **状況**：26ヶ月毎の打ち上げ窓が文明のリズムになる。最初の有人火星ミッション。
- **目標**：往復ミッションの成立（最大の壁＝EDL・放射線・帰還燃料）。前哨地（前進補給）の事前配置。
- **ドラマ**：片道6〜9ヶ月の閉鎖環境、太陽嵐との遭遇、帰還できるかの綱渡り。世界が固唾を呑む“最初の足跡”。
- **失敗の重み**：ここで全乗員を失うと、人類の宇宙熱は冷え込み（“宇宙の冬”イベント）資金と影響力が激減する。

### Act IV — 「種をまく」（2060s–2080s）｜火星定住地の自立
- **状況**：往復から「住む」へ。生き残りから持続可能性へ。
- **目標**：閉鎖系の物質循環をほぼ自立させる、現地での食料・水・酸素・建材生産、最初の火星生まれの世代。
- **ドラマ**：地球依存からの脱却を巡る対立。火星社会のアイデンティティ。補給途絶の危機。
- **指標**：「地球からの補給依存度」を下げ続けるのが中核KPI。

### Act V — 「揺りかごの外」（2090s–2130s）｜多惑星種としての安定
- **状況**：人類が二つ目の自立した文明圏を持つ。さらに外（小惑星帯・木星圏）への展望。
- **目標**：火星都市の自己再生産（人口・産業・統治）、地球—火星二元文明の安定、長期的なテラフォーミングの是非。
- **エンドゲーム**：複数の勝利条件へ収束（後述）。テラフォーミングは数世紀スケールの“賭け”として選択可能。

> **分岐**：プレイヤーの判断で歴史は変わる。協調路線なら早く・安定的に、競争放任なら速いが脆く事故多発。
> 大事故・地球危機（気候・紛争・経済恐慌）はランダム＋状況依存イベントとして差し込まれる。

## 6. 主要システム

### 6.1 勢力（Factions）
人類は複数の勢力で構成。プレイヤーは誘導する立場。
- **国家ブロック**（例：北米圏、欧州圏、東アジア圏、新興連合 など、史実を抽象化）
- **民間企業群**（打ち上げ事業者、資源採掘、生命維持メーカー）
- **国際機関**（宇宙開発の国連的調整機関 ＝ ゲーム後半で強化可能）
各勢力は **能力・予算・リスク許容度・相互信頼度** を持ち、独自に動く。
協調が進むほど効率↑だが、無理な統制は反発（離脱・サボタージュ・予算撤退）を招く。

### 6.2 人類指標（グローバルKPI）
画面常時表示の“文明ダッシュボード”。
- **Spacefaring Capacity（宇宙進出力）**：年間軌道投入質量、$/kg、再使用率
- **Off-world Population（地球外人口）**：LEO/月/火星の在住人数と健康
- **Self-sufficiency（自立度）**：火星定住地の地球補給依存度（↓が善）
- **Global Cohesion（地球協調度）**：勢力間信頼の総和。低いと計画が頻繁に崩れる
- **Public Will（宇宙への意志）**：世論・政治の支持。事故で急落、偉業で上昇。資金に直結
- **Knowledge（科学知）**：技術ツリーの進捗
- **Risk Debt（リスク負債）**：安全に投資せず急いだツケ。高いほど事故確率↑（“技術的負債”の宇宙版）

### 6.3 ミッション・パイプライン
各ミッションは段階を踏む（各段に時間・コスト・失敗確率）。
`設計 → 製造 → 統合試験 → 打ち上げ窓待ち → 上昇(LEO到達) → 軌道遷移 → EDL/着陸 → 表面運用 → (帰還)`
- **打ち上げ窓**：火星は26ヶ月周期。窓を逃すと2年待ち＝戦略の根幹。
- **失敗モード**：各段に固有の失敗（爆発・通信途絶・着陸失敗・生命維持故障）。質量・技術・Risk Debtで確率が決まる。
- **前進配置**：有人より先に物資・燃料・居住モジュールを無人で送る“積み上げ式”戦略（現実のNASA計画思想）。

### 6.4 経済モデル
- 資金源：公的予算（Public Will連動）／民間資本（投資回収を期待）／国際ファンド（協調度連動）。
- 支出：R&D、製造、打ち上げ($/kg×質量)、運用、人件・生命維持。
- **再使用とISRUがコスト構造を破壊的に変える**のを体感させる（$/kgが下がると一気に選択肢が開ける）。
- 民間は“儲かる軌道”（通信・観測・資源）に流れる。火星は当初赤字＝公的意志と長期投資が要る。

### 6.5 技術ツリー（実在技術ベース）
分岐例（全て原理実証済み or 理論的に妥当な範囲）：
- **推進**：使い捨て化学 → 再使用化学(メタロックス) → 軌道間燃料デポ → 核熱推進(NTP) → 核電気/イオン
- **ISRU**：水氷採掘 → 電解(水→O₂/H₂) → Sabatier推進剤合成 → 建材(レゴリス焼結/3Dプリント)
- **生命維持**：消耗品依存 → 物理化学リサイクル(水・空気) → 部分的バイオ循環(植物工場) → 準閉鎖生態系
- **EDL**：パラシュート＋逆噴射 → 超音速逆推進 → 大質量精密着陸
- **放射線/医療**：受動遮蔽(水/レゴリス) → 薬理対策 → 部分重力対応・遠隔医療
- **居住**：与圧モジュール → レゴリス被覆 → 地下構造 → 自己拡張する都市

### 6.6 人間（乗員）
乗員は使い捨ての駒ではない。**名前・専門・健康・被曝・士気・年齢**を持つ個人。
- 微小重力での骨・筋の劣化、放射線被曝の累積、隔離ストレス。
- 火星生まれ世代＝0.38g育ちの未知の健康問題（ゲーム内の不確実イベント）。
- 死は重い。Public Will に直結し、物語的な記録（メモリアル）として残る。

### 6.7 イベント / 危機システム
- **物理・運用**：ロケット爆発、着陸失敗、生命維持故障、太陽嵐(SPE)、塵嵐、機器故障。
- **政治・経済**：予算削減、国家間対立、商業バブル崩壊、地球規模の災害（気候・パンデミック・紛争）。
- **発見**：水氷の新鉱床、生命の痕跡（科学知と倫理的議論を生む）、技術的ブレイクスルー。
- イベントは状況依存（Risk Debtが高いと事故、Cohesionが低いと政治危機）＋一部ランダム。

## 7. 勝利条件・エンディング（単一ゴールにしない）

| エンディング | 条件のイメージ |
|---|---|
| **多惑星種の達成** | 火星定住地が地球補給ゼロでも自立・人口再生産が成立 |
| **持続可能な二元文明** | 地球と火星が長期に安定共存（協調度・自立度・人口が閾値） |
| **テラフォーミングの夜明け** | 数世紀計画を起動し、最初の不可逆な一歩を刻む（超長期の賭け） |
| **拡張する人類** | 火星を足場に小惑星帯・木星圏へ進出 |
| **失敗エンド** | 大事故連鎖＋Public Will崩壊で“宇宙の冬”、人類は揺りかごに引きこもる |

スコア＝速度・安全(失われた命)・自立度・協調度の複合。「速いが多くの命を失った歴史」と「遅いが堅実な歴史」を別軸で評価。

## 10. 実装方針（技術スタック提案）

リアルな数値モデル＋ターン制戦略は、まず**ロジックのコア**を作り込むのが正解。描画は後から差し替え可能にする。

- **言語/コア**：Python（数値モデルと相性良・本リポジトリの既存環境とも整合）。
- **アーキテクチャ**：
  - `core/`：純粋なシミュレーションエンジン（状態・物理/経済モデル・ターン進行）。UI非依存・テスト可能。
  - `data/`：実数の基準値（Δv表・$/kg・生命維持収支・技術ツリー定義）をデータ駆動で外出し。
  - `ui/`：最初はCLI/テキストで意思決定ループを成立させ、後にWeb(可視化)やデスクトップGUIへ。
- **設計原則**：「数値は全てdataに、ルールはcoreに、見た目はuiに」。リアリティ調整＝データ差し替えで完結させる。
- **検証**：物質収支・Δv・コストは単体テストで現実値と突き合わせる（“物理的に破綻しないこと”を保証）。

## 11. MVP（最小実証版）ロードマップ

> 目的：「神の視座で配分 → 時間を進める → 物理と確率で帰結 → 指標が動く」というコアループを、Act I〜IIIの縦スライスで体験できること。

- **M0：シミュレーションコアの骨格**
  状態モデル（勢力・資金・指標・技術）、ターン進行、データ駆動の基準値読み込み。CLIで1ターン回る。
- **M1：ミッション・パイプライン**
  設計→製造→打ち上げ窓→遷移→着陸の段階遷移と、質量/技術/Risk Debtに基づく失敗確率判定。
- **M2：経済と技術ツリー**
  資金源・$/kg・再使用/ISRUによるコスト変化、研究で選択肢が解放される実感。
- **M3：イベント/危機**
  状況依存＋ランダムのイベントカードと、Influenceによる介入。
- **M4：Act I〜IIIの縦スライス**

## 付録B：用語
- **Δv（デルタブイ）**：軌道変更に必要な速度変化量。宇宙の“距離”は km でなく Δv で測る。
- **ISRU**：In-Situ Resource Utilization。現地の資源で水・空気・燃料・建材を作ること。
- **EDL**：Entry, Descent, Landing。火星着陸最大の難所。
- **ECLSS**：環境制御・生命維持システム。閉鎖空間で人が生きるための物質循環。
- **SPE / GCR**：太陽高エネルギー粒子イベント／銀河宇宙線。放射線リスクの二大要因。
- **打ち上げ窓**：天体配置上、最小エネルギーで行ける限られた期間。火星は約26ヶ月毎。
