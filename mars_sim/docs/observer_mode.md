# 観測モード（Observer / Ambient Mode） — TERRA ASCENDANT

> **歴史の傍観者。** ゲームが完全に自律進行し、プレイヤーはそれを“鑑賞”する。
> 普段は手を出さず、人類史が勝手に紡がれていくのを眺める。そして**明示的に指示した瞬間だけ操作が戻る**。
> 三層モデル（[game_design §2](game_design.md)）の自然な拡張——自律世界はもともとAIで動いている。
> ここでは**自国の意思決定**も**神レイヤー**もAIに委ね、時間を自動で進める。

---

## 1. コンセプト

「神」は本来、世界を逐一操作する存在ではない。普段は歴史を流れるに任せ、**ここぞという時だけ介入する**。
観測モードはその神性を体験に変える。

- 自国は選んだ **ドクトリン（国家の方針AI）** に従って自走する。
- 自律世界（他勢力）は通常どおり各自のAIで動く。
- 神レイヤーは **運命の方針（Fate Policy）** に従い、地球規模イベントを自動で author / adjudicate する。
- 時間は自動で進み、プレイヤーは**クロニクル（年代記）**が書かれていくのを眺める。
- いつでも一時停止して [player_actions.md](player_actions.md) の任意の手を打てる。**打った瞬間、その範囲だけ操作が手に戻る。**

> ねらい：**創発的な物語**。毎回ちがう「人類が火星に至る／至れなかった別の歴史」が立ち上がる。
> 歴史書がライブで執筆されていくのを読む楽しさ。同時に、放っておいても面白い＝シミュレーションAIの品質保証にもなる。

---

## 2. 3つの自律ダイヤル（どこまで手放すか）

観測モードは ON/OFF の二択ではなく、**委譲の度合いを段階調整**できる。

### ダイヤル①：自国の自律（National Autopilot）
自国の意思決定を担う **ドクトリン**（プリセット or プレイヤー設定）。
| ドクトリン | 振る舞い |
|---|---|
| **慎重派** | 安全マージン厚め・前進配置を重ねる。事故が少なく遅い |
| **拡張派** | 攻撃的に窓を取りに行く。速いが `risk_debt` を溜めやすい |
| **協調派** | 共同ミッション・条約を優先。`cohesion` を育てる |
| **商業派** | 民間調達で $/kg を最小化。経済イベントに敏感 |
| **均衡派** | 状況に応じて上記を自動で切替（汎用おまかせ） |
| **カスタム** | プレイヤーが重み（安全/速度/協調/コスト）をスライダー設定 |

### ダイヤル②：神の自律（Fate Policy）
神レイヤーが地球規模イベントをどう振るうか。
| 方針 | 振る舞い |
|---|---|
| **静観** | ほぼ介入せず、自然発生イベントを穏当に裁定するだけ（凪の歴史） |
| **均衡** | 人類全体の前進を陰から均す。極端な独走・停滞を補正する“調停者の神” |
| **苛烈** | ドラマ重視。危機を能動的に投げ、世界を試す“厳しい神”（Mandateを積極消費） |
| **無作為** | 中立ランダム。気まぐれな運命。最もリアルで最も理不尽 |

### ダイヤル③：時間の流れ（Time Flow）
- 速度：`一時停止 / 等速 / 倍速 / 高速`。
- 巻き戻し（リプレイ）：起きた歴史を遡って見直す（state スナップショットから再生）。

## 3. 鑑賞 → 介入 → 鑑賞（“明示的に指示するまで”の中核）

観測モードの肝は、**いつでも介入でき、介入し終えれば自律に戻る**こと。

```
[自律進行：クロニクルが流れる]
   │  プレイヤーが何かしたくなる
   ▼
[一時停止 → 介入]  player_actions.md の任意の手を打つ
   │  指示が反映される（その範囲だけ手動）
   ▼
[自律進行に復帰]  指示した方針を引き継いで再び自走
```

### 介入トリガー（自動で一時停止し、判断を仰ぐ）
「ずっと見ているのは疲れる、でも肝心な場面は逃したくない」を両立する仕組み。
プレイヤーが**どの分水嶺で物語を止めるか**を設定する。
- 既定の分水嶺：初の有人火星到達、初の死者、宇宙の冬の到来、補給途絶クライシス、テラフォーミングの起動可否。
- ドクトリンが解決できない選択（重大な分岐）に達したら自動停止して問う。
- しきい値型：`public_will` 急落、`risk_debt` 危険域、自国が一番乗りを逃しそう……等を検知して通知。
- **完全放任**：トリガーを全部切れば、最後まで一切止まらず“通し鑑賞”できる（結末だけ見届ける）。

> これにより観測モードは「ただ寝かせて眺める」と「肝心な時だけ神が降りる」の二刀流になる。
> まさに *普段は歴史を流し、明示的に指示する時だけ介入する神*。

## 4. 鑑賞体験のUX

観測モードでは「見て面白い」ことが最優先。

- **クロニクル・フィード（年代記）**：何が起きているかをドキュメンタリ調で淡々と綴る流れる年表。
  - 例：「2041年・春——東アジア圏が月面で初のISRU推進剤生成に成功。世界がざわめく。」
  - 例：「2053年・第19打ち上げ窓——3勢力が同じ窓に殺到。赤い惑星への競争が始まる。」
- **太陽系ライブビュー**：地球・月・火星と遷移軌道上の船が実際に動く俯瞰。窓の開閉が可視化される。
- **ライブ・ダッシュボード**：人類指標（[game_design §6.2](game_design.md)）がスパークラインで刻々と推移。
- **ハイライト演出**：分水嶺イベントは画面を奪って大きく見せる（初の足跡、宇宙の冬、など）。
- **複数勢力トラッカー**：誰が今どこまで進んでいるかのレース表示（自国の順位も）。
- **しおり/クリップ**：気に入った瞬間にしおりを挟み、後で巻き戻して再生。

---

## 5. なぜこのモードを入れるのか（設計上の価値）

1. **創発的物語の鑑賞**：毎回ちがう人類史。リプレイ性とサンドボックス的な“眺める楽しさ”。
2. **学習装置**：初心者は介入せず眺めるだけで、Δv・窓・ISRU・協調の力学を体得できる（生きたチュートリアル）。
3. **AI品質の保証**：放置して面白い＝自律勢力AI・ドクトリン・運命AIが良くできている証拠。デバッグ/バランス調整にも有用。
4. **“神らしさ”の純化**：逐一操作しない神＝介入は希少で重い、という本作のテーマ（Mandate思想）を体験として強化する。

## 6. 実装方針（M0設計への要件）

このモードを後付けで足すのは難しいが、**最初からエンジンを正しく抽象化すれば“ほぼ無料”**で手に入る。鍵は一点：

> **「プレイヤーの意思決定」を、エンジンに差し込む `DecisionProvider`（意思決定プロバイダ）の一実装にする。**

```
core/ の ターンループは「誰が決めるか」を知らない。各意思決定点で DecisionProvider に問い合わせるだけ。

  DecisionProvider（インタフェース）
    ├─ HumanProvider     … 人間に選択を尋ねる（通常プレイ）
    ├─ DoctrineProvider  … ドクトリンAIが自国の手を決める（観測モードの自国）
    └─ FateProvider      … 運命の方針AIが神レイヤーの手を決める（観測モードの神）

観測モード = 自国を DoctrineProvider、神を FateProvider に差し替え、時間を自動送りするだけ。
介入 = その瞬間だけ HumanProvider に切り替え、終われば元のProviderに戻す。
```

- これにより通常プレイ／観測モード／部分自律（例：自国は手動・神だけ自律）が**同じエンジンで連続的に**実現できる。
- `core/` は UI 非依存・決定論的（[game_design §10](game_design.md)）なので、観測モードは「決定論的シミュレーションを Provider に駆動させて流すだけ」。
- 巻き戻し/リプレイは、ターンごとの state スナップショット（または乱数シード＋入力列）の保存で実現。
- **M0の必須要件に「DecisionProvider 抽象」を含める**（後から差し込めるよう、最初からこの境界を引く）。

## 7. モード一覧（本作の遊び方）

| モード | 自国 | 神レイヤー | 時間 | 体験 |
|---|---|---|---|---|
| **キャンペーン（標準）** | プレイヤーが直接指示 | プレイヤーが介入/裁定 | 手動送り | 戦略を練る本編 |
| **観測モード** | ドクトリンAIが自走 | 運命AIが自走（介入トリガーで停止可） | 自動送り | 人類史を鑑賞、肝心な時だけ降臨 |
| **部分自律（混成）** | 任意（自国は手動・神は自律 等） | 任意 | 任意 | 好みの委譲度でカスタム |

> 観測モードと標準モードは地続き。**鑑賞中にいつでも本編に“入って”いけるし、本編中にいつでも手放して眺められる。**
